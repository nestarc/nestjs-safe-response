# v0.15.0 Contract & DX Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the v0.15.0 Contract & DX Hardening release scope from `docs/superpowers/specs/2026-06-13-v0.15.0-contract-dx-hardening-design.md`.

**Architecture:** Keep the release additive and defensive. New catalog DX helpers live beside existing error and decorator APIs, field-selection hardening stays in `src/shared/field-selection.ts`, runtime validation helpers stay in `src/shared/response-helpers.ts`, and OpenAPI contract fixes stay in `src/swagger/global-errors.ts`.

**Tech Stack:** TypeScript, NestJS, Jest, ts-jest, tsd, @nestjs/swagger, Supertest.

---
